Hướng Dẫn Cài Đặt

Chọn thiết bị bạn đang sử dụng để xem hướng dẫn chi tiết và phù hợp nhất.

Điện Thoại

Hướng dẫn cài đặt chi tiết trên Android với Termux

Máy Tính

Hướng dẫn cài đặt đầy đủ trên Windows PC

Điện thoại

1

Cài Đặt Termux

Tải và cài đặt Termux từ link dưới đây (ứng dụng giả lập terminal cho Android).

Tải Termux tại đây
2

Cài Đặt Môi Trường

Mở Termux và chạy lệnh sau để cài đặt môi trường:

Lệnh cài đặt
pkg update && pkg upgrade -y pkg install python pip install requests colorama rich pycurl websocket-client termux-setup-storage
Lưu ý

Nếu có xác nhận, bấm y rồi Enter.

3

Chạy Tool

Sau khi cài đặt, chạy lệnh:

Lệnh chạy tool
cd /sdcard/download python Ltool.py

🎉 Chúc mừng! Bạn đã cài đặt thành công.

Máy tính

1

Cài Đặt Python

Tải Python 3.12.0 và cài đặt, nhớ tick chọn "Add Python to PATH".

Tải Python
Quan trọng

Phải tick chọn "Add python.exe to PATH".

2

Cài Đặt Thư Viện

Mở CMD và chạy lệnh:

Lệnh cài thư viện
pip install requests colorama rich websocket-client
3

Chạy Tool

Mở CMD và chạy (thay tên user của bạn):

Lệnh chạy tool
python "c:/users/(tên users)/downloads/Ltool.py"
Hướng dẫn

Thay (tên users) bằng tên thư mục user của bạn.

🎉 Chúc mừng! Cài đặt thành công.
