Hướng Dẫn Cài Đặt

Chọn thiết bị bạn đang sử dụng để xem hướng dẫn chi tiết và phù hợp nhất. Mỗi bước hướng dẫn đều được thiết kế rõ ràng, dễ hiểu và dễ thực hiện.

Điện Thoại

Hướng dẫn cài đặt chi tiết trên Android với Termux, tối ưu hóa cho thiết bị di động và dễ dàng sử dụng.

Máy Tính

Hướng dẫn cài đặt đầy đủ trên Windows PC, hỗ trợ tất cả tính năng và hoạt động ổn định nhất.

Hướng dẫn cài đặt trên điện thoại

1

Cài Đặt Termux

Đầu tiên, bạn cần tải và cài đặt Termux từ link dưới đây. Đây là ứng dụng giả lập terminal cho Android, cho phép chạy các lệnh Linux.

Tải Termux tại đây
2

Cài Đặt Môi Trường

Sau khi cài đặt Termux, mở ứng dụng và sao chép toàn bộ lệnh dưới đây để cài đặt môi trường cần thiết:

Lệnh cài đặt môi trường
pkg update && pkg upgrade -y pkg install python pip install requests colorama rich pycurl websocket-client termux-setup-storage
Lưu ý quan trọng

Trong quá trình chạy lệnh, nếu có hiển thị thông báo yêu cầu xác nhận, hãy bấm phím y rồi nhấn Enter để tiếp tục.

3

Chạy Tool

Sau khi cài đặt môi trường thành công, sao chép và dán lệnh dưới đây để bắt đầu sử dụng tool:

Lệnh chạy tool
cd /sdcard/download python Ltool.py

🎉 Chúc mừng! Bạn đã cài đặt thành công và có thể sử dụng tool trên điện thoại của mình.

Hướng dẫn cài đặt trên máy tính

1

Cài Đặt Python

Python là môi trường cần thiết để chạy tool. Hãy tải và cài đặt Python phiên bản mới nhất từ link dưới đây:

Tải Python 3.12.0
Lưu ý quan trọng khi cài đặt

Khi mở file setup, bắt buộc phải tích chọn "Add python.exe to PATH" để hệ thống có thể nhận diện lệnh Python từ bất kỳ đâu.

2

Cài Đặt Thư Viện

Mở Command Prompt (CMD) trên máy tính và sao chép lệnh dưới đây để cài đặt các thư viện cần thiết:

Lệnh cài đặt thư viện
pip install requests colorama rich websocket-client
3

Chạy Tool

Sau khi cài đặt xong thư viện, mở CMD và sao chép lệnh dưới đây để bắt đầu sử dụng tool:

Lệnh chạy tool trên Windows
python "c:/users/(tên users trên máy của bạn)/downloads/Ltool.py"
Hướng dẫn sử dụng lệnh

Thay (tên users trên máy của bạn) bằng tên thư mục user của bạn (ví dụ: Admin, User, Tên của bạn). Nếu bạn đã lưu file ở vị trí khác, hãy thay đổi đường dẫn cho phù hợp.

🎉 Chúc mừng! Bạn đã cài đặt thành công và có thể sử dụng tool trên máy tính của mình.
